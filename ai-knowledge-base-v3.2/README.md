# 腾讯微证券小红书 AI 知识库 v3.2

这是一份由现有 Markdown 知识库转换而来的 AI 可读版本，用于后续 Prompt 引擎、Brief、创意矩阵、审查面板和封面实验室调用。

## 文件说明

- `index.json`：入口索引，说明每个文件用途和推荐调用方式。
- `schema.json`：字段规范和检索原则。
- `product-features.json`：结构化产品功能知识库。
- `compliance-rules.json`：合规规则库，用于审查和生成约束。
- `compliance-rewrite-rules.cleaned.json`：单独清洗后的合规替代表达库。
- `content-templates.json`：小红书内容结构模板库。
- `phrase-library.json`：按内容类型整理的话术库，已做初步合规降噪。
- `brand-voice.json`：品牌语气、标准转化路径、风险提示和封面规范。

## 调用建议

不要把完整知识库一次性塞进 Prompt。建议按任务检索：

1. 根据 `contentType` 取 1-2 个内容模板。
2. 根据 `contentType` 和目标用户取 2-4 个产品功能。
3. 根据 `contentType` 取 1 个话术组。
4. 始终注入高风险合规规则。
5. 生成后再用 `compliance-rules.json` 和 `compliance-rewrite-rules.cleaned.json` 做二次审查。

## 关键清洗说明

原 Markdown 中部分表达营销感较强或有金融合规风险，本版本已做保守化处理，例如：

- “AI选股帮你找到好标的”改为“AI 分析可辅助理解公开信息”。
- “不错过任何机会”改为“减少公开信息遗漏”。
- “投资内幕/信息差套利”改为“公开信息整理/市场热度观察”。
- “收益稳健/本金安全性较高”改为“历史表现不代表未来收益/具体风险以官方页面为准”。
- “扣1私你/私信领取”改为“微信搜索腾讯微证券进入官方小程序了解”。

## 人工复核提醒

这份知识库已经适合进入 v3.2 Prompt 联调，但仍建议在上线前由合规或业务同学确认：

- 问元宝 AI 分析的真实能力边界。
- 微信热股榜单、投资 Top 榜的官方命名与展示边界。
- 是否允许在内容中提及开户、交易、活动或费用信息。
- 产品界面截图是否可以用于小红书封面和图文内容。
