# C3-V3

C3-V3 是由 `长鹅6号- Lunch空间站v1.1` 与 `C3-V1-main` 择优合并后的单入口 AI 内容创作工作台。

## 当前产品范围

- 唯一主入口：`开始创作`
- 业务线：腾讯理财通、腾讯微证券
- 工作流：要素配置 → 创意角度 → 生成内容 → 生成图片 → 预览审核
- 内容形态：小红书图文、视频脚本
- 可选能力：东方财富热点素材、手动素材、L4 人设、合规审查、视觉计划、批量生图、草稿箱

已移除原 v1.1 中未接通的爆款复刻、热点成文、玄学大师入口以及宠物功能。热点搜索作为“开始创作”内部的素材能力保留。

## 合并策略

- 产品外壳、主题、五阶段确认、草稿与历史：来自 v1.1
- 六角度结构化坐标采样与跨批次避重：来自 v1.1
- 场景/热点/产品约束 Prompt、视频脚本、反模板化、风险提醒：来自 C3-V1
- 图片提示词色号与技术文本清洗：来自 C3-V1
- 生图前正文确认门禁：保留自 v1.1
- 知识库：以 C3-V1 的增强版 KB v5.0 为准

## 本地运行

1. 将 `.env.example` 复制为 `.env.local` 并填写所需密钥。
2. 安装依赖：`npm install`
3. 启动：`npm run dev`
4. 完整检查：`npm run check`

热点搜索需要 `EASTMONEY_API_KEY`；未配置时不影响手动素材和主创作流程。

## 关键工程约束

- 创意角度固定生成 6 个，Prompt、解析器和热点槽位数量必须保持一致。
- `workflowContext` 是服务端阶段门禁，不能只依赖前端按钮禁用。
- 视频脚本不进入图片生成阶段。
- `none / medium / high` 是正式植入强度；历史 `low` 会兼容映射为 `medium`。
